## ✨ Features

- 🛍️ **Interactive Shopping Experience:** Product listing, detailed views, and smooth filtering with `react-select`.
- ⚡ **Global State Management:** Powered by Redux Toolkit and React Redux for fast, centralized store management.
- 📋 **Form Validation & Handling:** Seamless form integration using React Hook Form.
- 📊 **Visual Analytics:** Interactive charts for order/sales stats powered by Recharts.
- 🔔 **Alerts & Toast Notifications:** Real-time feedback using SweetAlert2 and React-Toastify.
- 📱 **Responsive UI Design:** Clean layout built using Bootstrap 5 and React Icons.

---

## 🛠️ Tech Stack

- **Core Framework:** React 18
- **Build Tool:** Vite 6
- **State Management:** Redux Toolkit, React-Redux
- **UI & Styling:** Bootstrap 5, React Icons
- **Routing:** React Router v6
- **Form Handling:** React Hook Form
- **Data Visualization:** Recharts
- **Feedback & Notifications:** SweetAlert2, React-Toastify
- **Dropdown/Selection:** React-Select
